# Memories photos

Upload the legacy conference-memory photos into this folder **without changing their filenames**.
`memories.yaml` stores only the basenames; `generate_memories.py` looks for them under `assets/memories/`.

Missing image files are simply omitted from the generated public page, so the site can be deployed before all photos are uploaded.
